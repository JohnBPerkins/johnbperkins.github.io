# johnbperkins.github.io

Personal site — served by GitHub Pages from `main` as plain static files
(`.nojekyll` disables Jekyll; there is no build step).

```
index.html                 markup + all copy
assets/css/style.css       tokens, editorial grid, motion
assets/js/background.js    WebGL ordered-dither field
assets/js/main.js          reveals, rail, nav, scroll-spy, count-ups
assets/og.png              1200x630 social preview card
assets/logos/              credibility-bar marks (see its README)
assets/files/              resume PDF
```

No frameworks, no dependencies, no build. Edit a file and push.

Local preview:

```sh
python3 -m http.server 4321   # then open http://localhost:4321
```

## Art direction

Editorial, not SaaS: a real grid, hairline rules instead of cards, viewport-scale
display type, mono for every label and number, and exactly one accent colour.

**There is no blur anywhere on the page** — no `backdrop-filter`, no `filter:
blur()`, no soft shadows. Everything is hard edges. Reveals move and fade only.

The accent is a single custom property:

```css
--accent:#d8ff54;   /* one line re-keys the whole page */
```

The backdrop palette is separate, in `RAMP` at the top of `background.js` — five
hex values, dark to bright. Change both together to shift the page's key.

## The backdrop

An ordered-dither field. A slow flowing light source is quantised to five tones
through an 8×8 Bayer matrix, so the illusion of a gradient comes entirely from
the dot pattern — the way newsprint does it — rather than from smooth blending.

Two details keep it crisp instead of mushy:

- the canvas renders at **CSS resolution**, not `devicePixelRatio`, and is
  upscaled by the compositor under `image-rendering: pixelated`, so one dither
  cell stays a hard square
- the field is sampled at the **centre of each cell**, so a cell is a single
  flat value. Sampling per pixel would reintroduce the smooth gradient the
  dithering exists to replace

Tone is raised to the 2.1 power before quantising, which keeps the mid-tones
sparse — without that the mid greens spread out and the whole thing reads as
camouflage. `--bg-fade` (set on scroll in `main.js`) sinks the field toward
black past the hero so body copy is read against near-black.

## Social preview

`assets/og.png` (1200x630) is referenced by `og:image` and `twitter:image`, so
pasting the link into LinkedIn, Slack or a DM renders a real card instead of a
blank rectangle.

It was generated by drawing to a `<canvas>` in the browser — same fonts, same
dither palette and Bayer matrix as the live backdrop, so it cannot drift from
the site's look. To regenerate after a copy or palette change, re-run that
canvas script and re-save the file. Absolute URLs are required in the meta tags;
relative paths are ignored by most scrapers.

Note: link previews are cached hard. After changing the image, re-scrape it in
LinkedIn's Post Inspector or Facebook's Sharing Debugger, or the old card
persists for days.

## Fallbacks

- `prefers-reduced-motion` — canvas off, no reveals, no ticker
- **No hardware acceleration**: if WebGL only succeeds *without*
  `failIfMajorPerformanceCaveat`, or the driver string is SwiftShader/llvmpipe,
  the page sets `html.no-gpu`, drops the canvas for a static CSS halftone in the
  same palette, and disables grain and the ticker. Nothing then repaints per frame.
- Preview that path on any machine with **`?nogpu=1`**.

```js
window.__dither   // { ramp, time, frames }
```
